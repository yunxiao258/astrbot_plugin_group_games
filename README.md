# AstrBot 群聊互动小游戏插件

群聊互动小游戏：**猜数字**、**成语接龙**、**猜歌名**、**谁是卧底**、**猜成语**、**24 点**、**猜价格**，并内置积分排行榜。大部分小游戏按群/会话隔离状态，互不干扰；谁是卧底采用全局单局锁（同时只允许一局进行）；游戏状态纯内存保存，超时自动清理；积分持久化到 JSON 文件（原子写）。

- 插件名称：`astrbot_plugin_group_games`
- 版本：1.1.0
- 作者：云晓
- 许可证：MIT（详见 LICENSE）

## 功能

### 经典小游戏

| 游戏 | 指令 | 说明 |
| --- | --- | --- |
| 玩法帮助 | `/游戏` | 查看全部游戏玩法列表 |
| 猜数字 | `/猜数字` | 开始游戏，随机 1-100（可配置）一个数字 |
| | `/猜数字 <数字>` | 猜数，反馈「大了 / 小了 / 猜中」；猜中后播报猜中者与次数 |
| | `/猜数字 放弃` | 揭晓答案并结束游戏 |
| 成语接龙 | `/接龙` | 开始游戏，随机内置成语起始（词库 240 条） |
| | `/接龙 <成语>` | 接龙：校验 4 字、首字等于上一条末字、在内置词库中、不重复 |
| | `/接龙 结束` | 结算并展示整条接龙链 |
| 猜歌名 | `/猜歌` | 开始游戏，从内置歌单（36 首中文流行歌曲）随机选一首，给出歌词提示 |
| | `/猜歌 <歌名>` | 猜歌，支持模糊匹配（全等、互相含子串、命中标题任一字面） |
| | `/猜歌 提示` | 获取歌手提示 |
| | `/猜歌 放弃` | 揭晓答案并结束游戏 |

### 谁是卧底（4-8 人，全局单局锁）

| 指令 | 说明 |
| --- | --- |
| `/卧底` 或 `/卧底 状态` | 查看当前局面状态（轮次、阶段、存活玩家名单） |
| `/卧底 加入` | 加入房间（需 4-8 人开局；全局同时只允许一局） |
| `/卧底 开始` | 开局：从 32 对近似词中随机分配词对，并随机指定 1 名卧底 |
| `/卧底 描述 <内容>` | 描述自己的词（每轮每人限 1 次，超长消息自动截断） |
| `/卧底 投票 <序号>` | 投票淘汰玩家（每人 1 票、不能投自己，平票随机淘汰） |
| `/卧底 退出` | 中途退出（退出后按当前人数自动结算胜负） |
| `/卧底 结束` | 提前结束本局并揭晓身份 |

流程：`加入 → 开始 → 逐轮描述 → 投票 → 淘汰`，直到一方获胜。

- 描述阶段限时 `spy_describe_seconds`（默认 60 秒），超时自动进入投票阶段
- 投票阶段限时 `spy_vote_seconds`（默认 30 秒），超时自动结算；无人投票则随机淘汰一名存活玩家
- 全部存活玩家描述/投票完毕即自动推进到下一阶段
- 胜负判定：卧底被票出 → 平民获胜（存活平民各 +3 分）；卧底存活至场上只剩 2 人 → 卧底获胜（卧底 +5 分）
- 游戏开始后不能中途加入；每轮自动播报剩余未描述/未投票人数

### 限时抢答挑战

| 游戏 | 指令 | 说明 |
| --- | --- | --- |
| 猜成语 | `/猜成语` | 开始：从 52 条题库随机出一道谜面（限时 `idiom_quiz_seconds` 默认 60 秒） |
| | `/猜成语 <成语>` | 抢答：答对 +2 分并展示成语解释 |
| | `/猜成语 放弃` | 揭晓答案与解释 |
| 24 点 | `/24点` | 开始：随机发 4 张 1-13 的牌（自动重发直至确认有解） |
| | `/24点 <算式>` | 提交算式（仅 + - * / 与括号，恰好使用 4 张牌），答对 +3 分 |
| | `/24点 放弃` | 揭晓本局牌面 |
| 猜价格 | `/猜价格` | 开始：从 24 件商品表中随机抽取一件，猜其价格 |
| | `/猜价格 <数字>` | 猜价：反馈「高了 / 低了」，差 ≤10 元时提示「很接近了」，猜中 +2 分 |
| | `/猜价格 放弃` | 揭晓答案并结束游戏 |

24 点安全校验：tokenize 词法白名单 + AST 白名单双重防线，仅允许整数与四则运算/括号，数字必须恰好等于牌面（每个数字使用次数与牌面一致），Fraction 精确求值（无浮点误差），杜绝幂运算、函数调用、属性访问等注入。

### 积分系统

| 规则 | 积分 |
| --- | --- |
| 谁是卧底：平民获胜 | 存活平民各 +3 分 |
| 谁是卧底：卧底获胜 | 卧底 +5 分 |
| 猜成语答对 | +2 分 |
| 24 点算出 | +3 分 |
| 猜价格猜中 | +2 分 |

- `/积分`：查看积分排行榜 Top 10
- 积分持久化到 JSON 文件（`scores_file` 配置，默认 `scores.json`），采用 tmp + os.replace 原子写，避免写一半损坏；文件缺失/损坏时静默回退为空表

## 防刷与超时机制

- 每轮游戏最多持续 `game_timeout_seconds`（默认 120 秒；谁是卧底整局兜底 600 秒），期间无人参与则后台清扫任务自动结束该游戏；再次操作会提示「已超时」
- 清扫间隔由 `sweep_interval_seconds` 配置（默认 30 秒）；即使清扫任务未运行，任何操作都会惰性检测超时并就地清理
- 猜成语答错进入冷却（默认 5 秒）；24 点每人提交、猜价格每人猜测均设最小间隔冷却（默认 3 秒），防止刷屏
- 谁是卧底防刷：描述消息截断 100 字、每轮每人限描述 1 次、每人 1 票、人数上限（默认 8 人）
- 配置脏值防御：非法配置自动回退默认值

## 安装

把插件目录放到 AstrBot 插件目录（如 `data/plugins/astrbot_plugin_group_games`）后重启 AstrBot，或在管理面板刷新插件列表即可。

## 配置项（_conf_schema.json）

| 配置 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `game_timeout_seconds` | int | 120 | 每轮游戏超时时间（秒） |
| `sweep_interval_seconds` | int | 30 | 后台清扫任务执行间隔（秒） |
| `guess_max` | int | 100 | 猜数字范围最大值 |
| `allow_repeat_idiom` | bool | false | 接龙是否允许重复成语 |
| `spy_min_players` | int | 4 | 谁是卧底开局最少人数 |
| `spy_max_players` | int | 8 | 谁是卧底人数上限（大群防刷） |
| `spy_describe_seconds` | int | 60 | 谁是卧底每轮描述限时（秒） |
| `spy_vote_seconds` | int | 30 | 谁是卧底每轮投票限时（秒） |
| `idiom_quiz_seconds` | int | 60 | 猜成语单题限时（秒） |
| `idiom_quiz_cooldown_seconds` | int | 5 | 猜成语答错后的冷却时间（秒），防止刷屏 |
| `game24_seconds` | int | 90 | 24 点单局限时（秒） |
| `game24_cooldown_seconds` | int | 3 | 24 点每人提交算式的最小间隔（秒），防止刷屏 |
| `price_seconds` | int | 120 | 猜价格单局限时（秒） |
| `price_cooldown_seconds` | int | 3 | 猜价格每人两次猜测的最小间隔（秒），防止刷屏 |
| `scores_file` | string | `scores.json` | 积分持久化 JSON 文件路径（相对路径基于插件目录解析） |

```bash
D:\uv-tools\astrbot\Scripts\python.exe test_group_games.py
D:\uv-tools\astrbot\Scripts\python.exe test_new_games.py
```
